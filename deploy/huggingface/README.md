# Relay

A personal assistant run by a small team of AI agents: a Concierge that understands requests,
and a Planner, Builder, Checker, and Reviewer that do the work, on a schedule or right away,
and notify you when it's done. Setup: docs/DEPLOY.md in the source repository.

Source code: https://github.com/Muhammad-Aitzaz-Khan/agent-orchestrator
